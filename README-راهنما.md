# راه‌اندازی EduBox با Firebase و GitHub Pages

این نسخه به پروژه Firebase قبلی شما (`taha-school-224e4`) متصل شده است. فایل `index.html` شامل تنظیمات عمومی وب Firebase است؛ این تنظیمات کلید خصوصی یا Service Account نیست.

## ۱) فعال‌کردن سرویس‌ها

1. وارد Firebase Console شوید و پروژه `taha-school-224e4` را باز کنید.
2. از **Build → Authentication → Get started → Sign-in method**، گزینه **Email/Password** را فعال کنید.
3. از **Build → Firestore Database** یک دیتابیس بسازید (اگر از قبل ساخته‌اید، همان را نگه دارید).
4. محتوای `firestore.rules` را در بخش **Firestore → Rules** جایگزین کنید و **Publish** بزنید.

## ۲) ساخت حساب مدیر (یک‌بار)

برای اینکه فقط مدیر بتواند امتحان ثبت کند و درخواست‌ها را تأیید کند:

1. در **Authentication → Users → Add user** یک حساب بسازید:
   - Email: `admin@taha-school-224e4.firebaseapp.com`
   - Password: یک رمز قوی که خودتان انتخاب می‌کنید.
2. پس از ساخت کاربر، مقدار **User UID** او را کپی کنید.
3. در **Firestore → Data** یک collection با نام `admins` بسازید.
4. یک document بسازید که **Document ID دقیقاً همان UID** باشد.
5. یک فیلد بولی اضافه کنید: `active` = `true`.
6. در سایت، در کادر نام کاربری مدیر بنویسید `admin` و همان رمز را وارد کنید.

نکته: شناسه مدیر را از طریق خود سایت نمی‌توان ثبت کرد؛ این کار عمداً فقط از Firebase Console ممکن است تا دانش‌آموز نتواند خودش را مدیر کند.

## ۳) انتشار روی GitHub Pages

1. یک repository بسازید یا repository سایتتان را باز کنید.
2. فایل `index.html` و `firestore.rules` را در ریشه repository بارگذاری کنید.
3. در **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید؛ branch را `main` و پوشه را `/ (root)` بگذارید و Save کنید.
4. پس از انتشار، آدرس GitHub Pages را باز کنید.

## ۴) ثبت‌نام دانش‌آموز

دانش‌آموز از سایت نام کاربری انگلیسی (حروف a-z، عدد، نقطه، خط تیره یا زیرخط؛ حداقل ۲ کاراکتر) و رمز حداقل ۶ کاراکتری انتخاب می‌کند. نام کاربری به‌صورت خودکار به یک شناسه داخلی Firebase تبدیل می‌شود؛ نیازی به ایمیل واقعی دانش‌آموز نیست. پس از ثبت‌نام، مدیر درخواست را در پنل خود تأیید می‌کند.

## داده‌ها کجا ذخیره می‌شوند؟

- `users`: مشخصات و وضعیت تأیید حساب‌ها
- `admins`: شناسه مدیران مجاز (فقط از کنسول Firebase)
- `exams`: برنامه امتحان‌های مشترک
- `results`: نتایج شخصی هر دانش‌آموز

## نکات مهم

- حساب‌های کاربران و رمزها توسط Firebase Authentication مدیریت می‌شوند؛ رمز عبور در Firestore ذخیره نمی‌شود.
- نتایج هر دانش‌آموز فقط برای خودش و مدیر قابل خواندن است.
- امتحان‌ها برای نمایش عمومی قابل خواندن هستند؛ فقط مدیر مجاز به افزودن یا حذف آن‌هاست.
- اگر دیتابیس یا Authentication در پروژه فعال نباشد، سایت آنلاین نمی‌شود تا سرویس‌ها و Rules را طبق مراحل بالا فعال کنید.
- این پروژه برای GitHub Pages است و به نصب Node.js یا Firebase CLI نیاز ندارد.
